# macOS · 整组任务移动

更新日期：2026-10-05。状态：实现完成；真实原生窗口的键盘预览、取消、提交、失败回滚和重启已验证。桌面 NSPanel 的直接鼠标拖动尚未验收。

## 使用范围

进入“整理桌面”，任务组上方出现“移动整组”手柄。拖动手柄可上下调整位置，横向越过屏幕中线后预览另一侧；松手保存。移动仅限当前显示器，不迁移到另一块屏幕。原来的行内手柄仍用于任务排序。

聚焦“移动整组”后，也可以用方向键预览：左右切换边缘，上下每次移动 20 个逻辑像素，Shift + 上下每次 100；Enter 保存，Esc 取消当前移动。没有进行移动时，Esc 退出整理。平时不显示整组手柄，重启默认为锁定状态。

预览期间只改变原生窗口和前端布局，不写入 SQLite。松手或 Enter 触发一次事务，确认成功后发布给其他窗口。失败恢复此前保存的位置并显示提示。Esc、失焦、打开“全部任务”、退出整理、显示器变化，以及其他任务或布局写入都会取消未提交的预览。

## 位置与保存

手势开始时固定工作区、任务组尺寸和坐标基准，用屏幕坐标差计算移动；窗口自身换到另一侧不会改变计算原点。按显示器的坐标缩放换算后，将垂直中心限制在工作区内，为拖动手柄、任务列表、溢出入口及整理工具栏留出空间。整理时的 `offset` 仍以整个 WorkArea 高度为基准，进入整理不会把同一个比例解释成另一段区域。

SQLite 继续保存相对高度 `offset`，不保存绝对像素。本轮只改变 Stack 的位置字段与更新时间，不改密度、任务内容、完成 / Snooze 状态、展示关系、排序槽位和 Undo。保存事务比较拖动开始时的完整 Stack，拒绝过期布局、已占用的目标边缘和无效位置。没有新增数据库版本。
