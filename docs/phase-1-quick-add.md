# Quick Add · 快速添加

2026-10-06，macOS 0.1.0 构建 7，Apple Silicon。实现 Revision 4 的快速录入入口。

## 使用

Control + Shift + Space 打开独立输入窗口，Enter 保存，Esc 或右上角关闭按钮取消。菜单栏、任务页工具栏及“设置 → 快速添加”提供相同入口。窗口沿用“精致 Mac / 温暖纸色 / 深色石墨”主题，首次使用时才创建 WebView；之后重复使用同一个窗口。

新任务默认未固定、不提醒，可勾选“固定到桌面”。时间识别默认开启，只识别标题开头的“今天 / 明天 / 后天 + 时间”，例如：

| 输入 | 保存标题 | 截止时间 |
| --- | --- | --- |
| 明天下午3点 联系客户 | 联系客户 | 明天 15:00 |
| 后天09:30 开会 | 开会 | 后天 09:30 |
| 今天下午三点半 复盘 | 复盘 | 今天 15:30 |
| 明天3点三角函数复习 | 三角函数复习 | 明天 03:00 |

支持数字 / 中文小时、`HH:MM`、`点`、`点半`及`点…分`；带时段的小时为 1–12，直接数字时间为 24 小时制。保存前显示识别结果。中午、晚上存在歧义时提示使用 24 小时制；夏令时中不存在的本地时间拒绝保存。“晚上12点”按该晚之后的次日零点处理。

关闭“识别时间”后，整句作为普通标题保存，不设置截止时间。未匹配语法的输入也按普通标题保存，不猜测“周五”“下个月”等表达。标题最多 500 字、一行，识别出时间后仍须有任务标题。今天已过的时间可以显式保存为逾期任务。识别截止时间不会自动开启系统通知；需要提醒时再编辑任务勾选“提醒我”。

## 焦点和保存

显式打开时获取焦点；取消或保存成功后，仅在 Sidelet 仍位于前台时恢复之前的应用 / 自有窗口。主动切到其他应用时自动收起并保留草稿，不把焦点抢回来。构建 8 保持快速添加窗口复用；90 秒销毁试验因 WebKit 保留进程增加而撤回，见 [内存优化](phase-1-memory-lifecycle.md)。再次打开继续填写；明确取消或保存成功后清空输入并恢复默认选项。任务页已有草稿独立保留。退出应用后不保存未提交的快速添加草稿。

后端重新解析原始输入并调用现有 SQLite 创建事务，不信任前端预览传来的截止时间。每次打开带会话版本，重复打开不重置当前输入；保存期间拒绝重入、重复提交及取消，成功后拒绝旧会话重放。预览和保存使用同一次打开的日期基准，即使跨午夜也不会悄悄改变已预览的“明天”；重新打开会重新预览。

数据库操作在控制器工作队列执行，UI 更新回到主线程。写入失败不创建任务、不关闭窗口，保留标题和选项，重新聚焦输入框后可以直接 Enter 重试。保存期间若用户切到外部应用，完成时不抢回焦点。

macOS 快捷键使用独立 Carbon handler 和独占注册，与 Control + Option + T 分开管理。冲突时设置页显示错误，备用入口继续可用；解除占用后重启重新注册。拥有注册的 Stack 退出时释放快捷键。Windows 实现独立 RegisterHotKey 入口，但尚无 Windows 实机验证。

## 验证

证据目录为 `build/results/quick-add-native-20261006/`，不进入 Git。`report.json` 记录最终结果及测试范围。

- 解析和会话共 5 项顶层单元测试，含时间前缀、中文数字、普通标题、关闭识别、错误时间、年份 / 闰年 / 夏令时、重复打开 / 提交、旧会话、取消、失败重试及保存期间失焦。
- 真实 SQLite 集成测试注入 INSERT 失败，验证数据不变、草稿会话保留、跨午夜重试日期相同、重复提交拒绝、默认未固定 / 不提醒、关闭识别后可固定。
- `regression.log`：19 项前端测试、Go race / vet、33 项原生路由、16 项透明背景、9 项 Dock 断言通过。最终打包再次通过前端检查（0 错误 / 0 警告）、所需 Go 测试和 vet；最终控制器、Quick Add 和集成测试另行通过 race 检查。Windows amd64 / arm64 交叉编译及 amd64 vet 通过。
- 独立 bundle ID / 资料目录实测首次创建、中文时间预览、Enter 保存、Esc 取消、默认未固定 / 不提醒、明确固定、无效时间拒绝、关闭识别保存整句、主动切换应用后草稿保留。数据库有四条合成任务，仅第二条固定，零提醒，完整性为 `ok`。
- SQL trigger 模拟写入失败，标题和固定选择保留；移除 trigger 后重试只增加一条任务。最终构建验证输入框自动重新聚焦，直接 Enter 重试通过。
- 外部测试应用的只读日志确认取消 / 成功保存之后，外部应用和原输入框恢复焦点。该入口标记 `source=fixture-request`、`globalKeyTested=false`，不代替真实全局按键。
- 快捷键探针验证使用前可注册、运行时被占用、退出后释放。第二个独立实例产生冲突提示，仍能从设置打开 / 取消。原生断言直接检查 Carbon 事件数据的回调隔离，不向系统发送按键。
- 三套主题截图确认窗口一致；从设置和快速添加返回任务页后，未保存的主窗口标题草稿仍在。

构建 7 的 200 次快速添加、普通模式 / 诊断模式十分钟恢复、提醒 / 导出 / 重启工作流与内存原因分析已完成，见 [稳定性复测](phase-1-build7-stability.md)。功能工作流通过；初始空闲 CPU 略超首轮目标，资源保留的完整归因仍待完成。

真实 Control + Shift + Space 从外部应用到达回调、中文输入法候选确认 Enter、多屏 / Spaces / 全屏下打开仍待实测。Computer Use 的按键操作针对指定应用，不能当作全局快捷键测试；中文测试使用 AX 设置值，不能当作真实输入法验证。原有 P0 待验收状态保持不变。
