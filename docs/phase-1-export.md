# JSON / CSV 导出

2026-10-06，macOS 0.1.0 构建 6。对应 Revision 4 的 V1 数据导出要求。

## 使用

“设置 → 导出任务”选择 JSON 或 CSV，在系统保存窗口选择文件名和位置。默认文件名带本地日期及时间；原生保存窗口负责已存在文件的覆盖确认。保存完成后显示文件名和任务数量，取消会显示“已取消导出”，失败后可以重试。

导出包含点击时已经保存的全部任务：待办、已完成、未固定、延后、临时任务均包含，尚未到清理时间的已完成临时任务也包含。不受当前任务页筛选影响。未提交草稿不会导出，返回任务页后草稿继续保留。

这是数据导出，不是 SQLite 备份；应用偏好、运行期选择 / Undo 状态及系统通知凭据不在导出范围内。目前没有导入功能，不宣称可直接恢复资料目录。

## 文件格式

JSON 的顶层为 `format="sidelet"`、`version=1`、`appVersion`、`exportedAt`、`todos`、`stacks`。任务包含标题、备注、完成、优先级、临时属性、提醒、延后、创建 / 修改时间及桌面关系；Stack 包含显示器、左右边缘、位置、密度与时间。任务和布局时间沿用 Unix 毫秒，未设置时为 0；`exportedAt` 为 UTC ISO 8601。空列表写为 `[]`，中文及多行文本保持原值。

CSV 使用 UTF-8 BOM 和 CRLF，首行为字段名，每条任务占一条记录。时间使用 UTC ISO 8601（包含 `Z`，未设置时留空），不采用有歧义的地区日期格式。共 21 列：

```text
id,title,description,completed,priority,temporary,dueAt,completedAt,
snoozedUntil,remind,remindAt,reminderSentAt,createdAt,updatedAt,
displayMode,stackId,sortOrder,displayId,side,offset,density
```

CSV 中逗号、引号、多行备注由标准 CSV 编码器转义，换行统一为 CRLF。没有关联 Stack 时布局字段留空；CSV 不单独表示没有任务的 Stack。公式风险文本（以 `= / + / - / @` 开头，含前置空白，或以 Tab / CR / LF 开头）前加单引号，避免表格应用执行公式；JSON 保留原文本，适合精确保留数据。

## 保存与线程

从真实 SQLite 的单一只读事务取得任务及布局，编码后再打开保存窗口。保存窗口和文件写入在单个后台操作中等待，控制器队列继续处理提醒等消息；只在主线程显示原生窗口及发布结果。原生窗口仅从主任务窗口请求，并发导出拒绝重复操作，内部完成消息不能通过前端伪造。

文件先写入目标目录的临时文件，Sync / Close 成功后 Rename 替换；失败清理临时文件，已有导出不被部分内容覆盖。Unix 创建权限为 0600，Windows 遵循目录 ACL。要求格式与文件名后缀匹配；按目录实际身份拒绝写入当前资料目录及其子目录，符号链接和大小写别名不能绕过，避免覆盖 `settings.json` 等正在使用的数据。
