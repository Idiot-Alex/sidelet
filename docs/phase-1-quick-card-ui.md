# 快速卡片 UI 与内容尺寸

日期：2026-10-07。macOS 本地预览构建 20。

## 变化

- 收紧顶部与内容间距，标题统一为 18px；重要程度沿用“普通 / 重要 / 紧急”，旧值 1 继续显示为“重要”。普通任务不额外显示徽标。
- 重要程度与截止时间组成紧凑元信息区，截止时间带时钟图标，逾期采用已有警示色。无截止时间不占位。
- 无备注或仅空白备注不生成备注段落；短卡片按实际内容收紧，首选高度范围 160–390px。长标题与长备注在内容区滚动，底部操作区固定可见。
- “完成 / 稍后 / 编辑”三列等宽，高度均为 36px，沿用统一图标与文案对齐。延后菜单显示三个时间选项和独立返回入口；切换任务或进入编辑时清理菜单状态。
- 编辑仍保留 390px 输入空间，保存失败保留输入与错误信息。显式编辑请求首帧采用编辑高度，迟到的阅读尺寸不能缩短正在编辑的窗口。
- 继续使用精致 Mac、温暖纸色、深色石墨的现有主题变量，不增加字体、图标库或动画依赖。

## 窗口与交互

前端在渲染确认中带上卡片尺寸，后端校验会话后再显示；后续内容变化通过一个可释放的 ResizeObserver 与组件更新测量通知。测量会补回旧视口截断的内容高度，避免从较矮的共用弹窗切回卡片时永久截短。原生层继续按来源屏幕 WorkArea 限制大小与位置。

缩放后同步完整命中区域，继续使用卡片的直接输入方式。实测初版点击取消后，窗口缩短把鼠标留在外侧，触发 500ms 收起。因此后续尺寸变化仅在鼠标原本位于卡片内时调整纵向位置，让新窗口继续覆盖鼠标；外部鼠标不改变位置，边界仍受 WorkArea 约束。macOS 复用面板已有的鼠标事件坐标，Windows 使用系统光标与窗口矩形。

`quick-size` 带任务会话代次；共用弹窗还沿用视图与弹窗代次校验。已关闭、等待新内容、旧会话及快速添加替换后的尺寸消息都不能改变当前窗口。上一轮来源标签 / 实际 `popup` 窗口的悬停修复保留。

浏览器预览在工作区恢复尺寸时重新计算卡片首选宽度，避免小视口产生的窄尺寸永久保留。
