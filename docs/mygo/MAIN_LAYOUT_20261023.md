# 主界面布局整理

2026-10-23，build 41。延续 Mac、纸感、石墨三主题，减少新建区与顶部的常驻控件，统一任务列表的信息顺序。

## 行为

- 新建任务默认折叠备注，保留标题、固定到桌面、更多选项和添加按钮；点“添加备注”展开并聚焦输入。收起已填写的备注显示“备注 · 已填写”，提交时仍保存内容。已有任务编辑直接显示完整备注。
- 从新建表单进入已有任务编辑，再保存或取消，恢复新建备注及原来的展开状态。沿用 build 40 的草稿、日期和并发修改保护；草稿仍只保存在当前窗口内存中。
- 顶部保留“快速添加、设置、更多”。“整理桌面、隐藏标签、隐藏窗口”移到系统原生菜单；整理期间显示“完成整理”，隐藏标签后显示“显示标签”，恢复入口直接可见。标签隐藏时仍禁止整理。
- 重要程度和日期固定在标题下方；复选框、标题首行与操作按钮对齐，备注和附加状态沿同一左边距排列。桌面 / 提醒等附加状态降低视觉权重，逾期和紧急状态保留强调色。
- 新建栏略收窄，将更多宽度留给任务标题；沿用原生绘制与现有布局机制，无新增依赖、后台轮询或数据库变更。

## 验证

- 全量 `scripts/test-regression.sh` 通过，包含 race、vet 和 Windows 发布工具检查。
- 新增两项三主题交互测试，覆盖菜单内容、关闭与键盘重开、模式恢复入口、草稿保留、备注展开聚焦、收起后提交和编辑返回；原有草稿、日期、排序、设置及快捷保存测试继续通过。
- 长标题几何检查覆盖多个宽度，确认重要程度 / 日期始终在标题下方，标题、按钮和编辑栏不重叠。
- 原生渲染器生成主界面 / 设置 / 错误状态 15 张、新建 / 编辑 / 恢复状态 9 张预览，检查三主题与窄窗口。证据在 `build/results/main-layout-20261023/`。

预览命令：

```sh
SIDELET_UI_VISUAL_DIR="$PWD/build/results/main-layout-20261023" \
SIDELET_FORM_VISUAL_DIR="$PWD/build/results/main-layout-20261023/forms" \

```

菜单交互由 MyGo 无窗口测试器验证；渲染预览不代表系统菜单的真实鼠标 / 键盘操作或中文输入法候选验收。
