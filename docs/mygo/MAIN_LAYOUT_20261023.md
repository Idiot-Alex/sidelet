# 主界面布局整理

当前行为见文末 build 46 说明；build 41–45 段落保留各次实现与验收的历史状态，不代表当前透明范围。

2026-10-23，build 41。延续 Mac、纸感、石墨三主题，减少新建区与顶部的常驻控件，统一任务列表的信息顺序。

## 行为

- 新建任务默认折叠备注，保留标题、固定到桌面、更多选项和添加按钮；点“添加备注”展开并聚焦输入。收起已填写的备注显示“备注 · 已填写”，提交时仍保存内容。已有任务编辑直接显示完整备注。
- 从新建表单进入已有任务编辑，再保存或取消，恢复新建备注及原来的展开状态。沿用 build 40 的草稿、日期和并发修改保护；草稿仍只保存在当前窗口内存中。
- 顶部保留“快速添加、设置、更多”。“整理桌面、隐藏标签、隐藏窗口”移到系统原生菜单；整理期间显示“完成整理”，隐藏标签后显示“显示标签”，恢复入口直接可见。标签隐藏时仍禁止整理。
- 重要程度和日期固定在标题下方；复选框、标题首行与操作按钮对齐，备注和附加状态沿同一左边距排列。桌面 / 提醒等附加状态降低视觉权重，逾期和紧急状态保留强调色。
- 新建栏略收窄，将更多宽度留给任务标题；沿用原生绘制与现有布局机制，无新增依赖、后台轮询或数据库变更。

## 2026-10-24：build 44 界面整理

新建表单增加“收起”，先刷新 SQLite 草稿再收起；写入失败保持编辑器和重试入口可见。收起后显示“继续新建草稿”及标题，重新展开保留完整备注、日期和选项；重启发现草稿时自动展开。添加成功回到列表并将键盘焦点交还新增入口。沿用 build 43 的草稿格式和 schema 2，不迁移数据库。

标题字号调整为 15 px，重要程度、日期、提醒、桌面和临时状态合并为可换行的一组辅助信息；备注预览最多一行，原始换行和完整内容保留在编辑器中。列表与编辑区去掉外层边框，保留分隔线和悬停反馈。桌面位置改为列表下方的紧凑入口，展开后横向排列边缘、位置和密度控件。具体桌面操作继续显示文字与图标，保留悬浮说明。

设置页改为连续分组，缩小主题预览、删除重复说明，保留权限状态、系统设置入口和导出范围说明。三主题共用同一布局。浮动卡片的次要按钮去掉边框，备注编辑区利用可用高度；阅读高度计算、编辑窗口尺寸、锚点和透明侧栏命中规则不变。没有新增依赖、字体、常驻动画或轮询。

## 2026-10-24：build 45 半透明玻璃

外观设置新增“半透明玻璃”开关，作用于主窗口、设置页和浮动任务卡片。macOS 使用系统 NSVisualEffectView 背景模糊，三主题分别提供半透明底色；文字和主要操作保持实色，输入框保留较高不透明度。没有使用窗口整体透明度，也没有新增动画或后台轮询。侧边任务标记的空白区域继续完全透明，快速添加窗口沿用原来的实色外观。

原生材质只在开关或系统辅助功能偏好变化时更新；系统要求降低透明度 / 提高对比度时恢复实色。平台不支持原生模糊时，绘制层使用原有不透明主题。Windows 窗口创建时预备原生材质能力，Windows 11 原生合成器可用时才启用玻璃；MyGo 对此类窗口使用 Alt / F10 弹出菜单。Windows 两架构仅完成交叉编译，本轮未完成 Windows 真机材质或菜单验收。

macOS 浮动卡片的鼠标承接窗口改用轻微透明的命中底面，避免遮住系统模糊；原有窗口顺序和事件转发保持不变。原生材质与卡片内容一起裁切圆角，避免四角出现方形背景。三主题的实色主题对象保持不可变，侧栏不会误用玻璃颜色。

设置存入 `preferences.appearance.translucent`，继续使用 SQLite schema 2。旧资料默认关闭，开关提交成功后才更新界面，写入失败保留原状态和错误提示。开启后回退旧构建应使用配套资料备份，避免旧版严格 JSON 读取器不识别新字段。

验证结果：

- 应用 / internal 包测试、race、vet 和 `git diff --check` 通过；Windows amd64 / arm64 交叉编译通过，ARM64 macOS 构建和 ad-hoc 签名校验通过。
- 三主题原生渲染测试覆盖背景 alpha、前景不透明、无材质 / 高对比度 / 降低透明度回退、浮动卡片与侧栏透明空白；真实 SQLite 测试覆盖设置保存、失败不发布、草稿和任务保持、重启恢复。
- macOS M3 使用 Computer Use 操作独立内存实例，开启玻璃、切换深色主题，检查主窗口、设置和卡片圆角；“稍后 → 返回 → 编辑 → 中文粘贴 → 保存 → 再编辑 → 取消”正常，内容未空白，取消后保留已保存标题。没有向日常任务写入合成数据。窗口截图用于检查布局、文字和交互，单窗口捕获不能独立证明桌面背景的合成模糊强度；也不代表真实中文输入法候选或多屏验收。
- 已正常退出日常 build 44，备份完整应用和资料后更新 `/Applications/Sidelet.app` 为 build 45，并通过界面开启玻璃。升级前后任务、草稿、回执及其他表哈希一致，metadata 唯一变化为 `preferences.appearance.translucent = true`；完整性为 `ok`，schema 仍为 2。

## 2026-10-26：build 46 收录最新界面行为

build 46 收录 `0856efc` 与 `0d4f5a7` 的界面调整，并为它们分配新的打包构建号。主窗口和设置页使用实色背景，任务列表用细分隔线组织内容，不再提供主窗口透视。新建 / 编辑仍按需展开，继续使用已有的草稿持久化与失败保护。

设置导航分为“外观、桌面任务、通知与启动、数据与快捷键”。外观保留三主题和 macOS Dock 设置；桌面任务包含边缘、中心位置、密度，以及“悬浮任务半透明”；通知与启动集中系统权限和启动选项；数据与快捷键提供导出和快捷键状态。桌面位置入口已从任务列表移至设置。

半透明仅作用于悬浮任务卡片，macOS 使用原生磨砂材质，Windows 使用无模糊透明合成；系统降低透明度 / 提高对比度或平台能力不可用时退回实色。当前偏好字段为 `preferences.appearance.desktopTranslucent`，默认关闭。旧 `translucent` 字段仅为读取兼容而保留，不再控制界面，也不会自动开启新的悬浮透明选项。数据库 schema 仍为 2。

侧边标签按优先级显示不同颜色，重要 / 紧急以两条 / 三条标记区分，展开后同时给出文字；到期状态另以小圆点提示。标签周围空白继续透明，没有新增整条侧栏背景。

本轮改动集中在版本、打包校验和文档，不把之前 build 45 的实机透明验收直接当成新版 Windows 行为已经通过。打包与官网下载核验流程见 [build 46 打包记录](MACOS_PACKAGE_20261026.md)。
