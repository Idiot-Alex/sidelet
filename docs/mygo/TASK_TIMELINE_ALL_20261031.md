# 三页签时间轴 · build 53

在 build 52 的待办时间轴基础上，将已完成和全部页签统一为同一套日期分组布局。

## 日期与状态规则

- 待办：保留已逾期、今天、明天、后续日期、未安排分组，按预计完成时间升序。
- 已完成：按任务的实际 `CompletedAt` 倒序，同一天最近完成的在前，使用今天、昨天或具体日期；未记录完成时间的任务放入“完成日期未知”，不推测或使用预计完成时间替代。
- 全部：按 `DueAt` 升序分组，同一计划日期的已完成和未完成任务放在一起。过去日期保留各自分组，不合并成逾期；逾期状态仅显示在未完成任务上，未设置计划日期的放入“未安排”。
- 已完成任务保持勾选、淡色和删除线。已完成页的行内显示“完成于 HH:mm”；全部页区分“完成于 日期 时间”和“计划 日期 时间”。
- 三个页签显示各自的排序说明，使用相同的节点、细线、间距、搜索和行操作。空日期组隐藏，搜索后计数仅包含匹配任务。
- 相同时间或未知日期的任务保留原有快照顺序，不修改桌面排列、任务数据或工作日志。按当地午夜刷新相对日期，只有未完成任务需要截止时间刷新，无新增持续轮询。
