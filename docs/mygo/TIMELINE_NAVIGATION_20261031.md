## 界面行为

- 筛选页签、搜索和“回到今天”固定在任务列表上方；列表单独滚动，Cmd+F 聚焦搜索不再跳回列表顶部。
- 待办、已完成和全部各自保留本次运行的滚动位置与日期折叠状态，不写入 SQLite。日期折叠按实际年月日记录，跨日后不会把昨天的折叠状态套用到新的今天。
- 点击日期标题收起或展开该组；“回到今天”会展开并定位当前页签的今天分组，没有今天任务时禁用。搜索时自动展开所有匹配日期，清除搜索后恢复原有折叠状态。
- 编辑区与任务列表独立滚动，保存、取消和收起按钮固定在编辑区底部；窄窗口切为上下布局。收起日期组不丢弃正在编辑的草稿。
- 日期选择的内联回退面板打开时自动进入编辑区可见范围，原生日期弹窗行为保持不变。

## 应用实例

显式使用 `-memory`、`-data-dir` 或 `-output` 的实例显示“Sidelet · 演示”，主界面提示“演示实例 · 独立数据，不影响日常任务”，快速添加窗口也带演示标识。默认启动保留 Sidelet 名称、原 bundle ID 和原资料目录。

持久化实例启动前规范化资料路径，使用路径摘要接入 MyGo 的单实例交接。相同资料再次启动时直接激活已有任务窗口，已最小化窗口会恢复；不会再次打开数据库。独立资料允许同时运行，内存实例不参与持久化单实例限制。

MyGo 的交接标识还包含应用包标识，因此保证范围是相同应用标识与相同资料目录；不同标识的开发程序不保证交接。原有资料文件锁继续作为写入保护，未用单实例交接替代数据库保护。
