## 行为

主窗口“待办”使用按本地预计完成日期分组的轻量时间轴，细线与小节点标识日期，任务自身保留完成圆圈、标题、备注、优先级、日期状态及操作按钮。

- 分组顺序：已逾期 → 今天 → 明天 → 后续各日期 → 未安排。只有包含任务的分组才显示。
- 已逾期包含所有预计完成时间早于当前时刻的任务，也包含今天早些时候到期的任务。跨年的未来日期显示年份。
- 有时间的任务按预计完成时间升序；相同时间和未设置时间的任务保持快照中的原有顺序。分组排序不修改模型或 SQLite，不影响桌面标签手动排列。
- 搜索先筛选任务再生成分组，组内数量对应当前搜索结果。完成后空分组移除，撤销或恢复后任务返回对应日期。
- 只在下一次截止时间或当地午夜请求刷新，不新增持续轮询；未安排任务不需要时间刷新。午夜使用当地日历边界，覆盖夏令时的 23 / 25 小时日期。
- 三主题与窄窗口共用布局。日期节点不参与点击，不与任务完成圆圈混淆。编辑区继续使用独立的稳定节点，跨日分组不重置输入草稿。
- 本轮只改待办页；已完成、全部以及桌面整理模式保持原有列表。工作日志继续按实际完成日期展示历史。
