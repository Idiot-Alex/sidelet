# MyGo 0.5.1 升级记录

日期：2026-10-16。Sidelet 0.2.0 build 28；升级前基线提交 `d3945c0`（包含 SQLite）。

## 迁移

- SDK 从 `v0.2.16` 固定升级到 `v0.5.1`，同步整理依赖。
- 原生控件改用受生命周期检查的 `ui.Element` 值；带状态的控件在构造前设置 `Context.Key`。
- 日期分段输入的跨帧焦点切换改用 `ui.Handle`；剪贴板回调使用 `Context.Services()`，不保存临时元素。
- 回归发现 0.5.1 的合成输入后 Enter 会进入编辑器命令并提交。增加合成状态保护，阻止选词回车创建任务或插入换行；正常提交与换行仍有效。
- 保留既有主题、SQLite 数据结构和应用标识。

## 验证

- 原生与内部包全量测试、race、Go vet、MyGo vet 通过。
- 新增单行/多行合成输入回归，覆盖选词回车、提交中文后正常保存/换行；原有日期键盘导航、主题、卡片和持久化回归通过。
- macOS arm64 构建、签名检查通过；Windows amd64 / arm64 交叉构建通过。
- AppKit 诊断 10/10 通过：透明空白穿透、被动卡片、编辑焦点、取消位置恢复、重复编辑、拖动/取消、完成和清理。该诊断直接检查应用窗口状态，不是硬件悬停验收。
- Mac 隔离 SQLite 资料实机检查：中文标题/多行备注保存、编辑保存、固定到桌面、三种主题切换、快速添加日期识别及回车保存、退出重启恢复通过。
- 实机中文文本通过 AX 设置验证；自动合成输入测试不等于真实中文输入法候选窗验收。Windows 实机、跨屏/Spaces、纯鼠标悬停仍不能据此宣称全部验收。
- 本机快捷键提示占用，未更改其他应用快捷键；快速添加窗口入口正常。登录项显示系统未找到测试应用，未改系统登录设置。

实机证据在忽略目录 `build/results/mygo-051-20261016/`。

## 同 SQLite 数据短时内存对比

M3 Max / macOS 26.6.2；相同两条任务（一个固定桌面）、Mac 主题、主窗口打开；各版本单独启动，各预热至少 10 秒，随后每 5 秒采样，共 30 秒 / 7 个点。两者都是 SQLite 版本、CGO=0、相同 stripped 构建参数；基线从 `d3945c0` 重建。测试副本不访问个人任务。

| 指标（中位数） | v0.2.16 | v0.5.1 |
| --- | ---: | ---: |
| RSS | 123.42 MiB | 114.61 MiB |
| footprint | 46.95 MiB | 53.91 MiB |
| 进程数 | 1 | 1 |

RSS 降约 8.81 MiB，footprint 升约 6.96 MiB。因此本轮不能宣称升级降低实际内存成本。旧版 footprint 在采样期间从 60.24 MiB 降至 46.95 MiB，说明短时窗口仍受回收时机影响。本次仅小样本静置检查，不能推导长时间、多任务或反复编辑表现；文本缓存上限的收益也未在此场景得到验证。
