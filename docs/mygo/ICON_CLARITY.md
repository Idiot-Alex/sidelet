# 图标含义与可见文字

2026-10-18，build 33。针对 MyGo 主界面部分操作只能靠悬停猜测的问题，调整图标与可见操作文字。

| 操作 | 调整 |
| --- | --- |
| 设置 | 滑杆改为齿轮，并显示“设置”文字 |
| 隐藏主窗口 | 移除类似退出的箭头，改为窗口与横线，并显示“隐藏窗口” |
| 桌面标签显隐 | 月亮改为眼睛 / 划线眼睛；按钮及菜单栏统一为“隐藏标签 / 显示标签”，避免被理解成切换主题或关闭提醒 |
| 任务放到桌面 | 使用显示器与加号 / 减号，并显示“放到桌面 / 移出桌面”；完整任务上下文仍保留在无障碍名称中 |
| 日期选择 | 使用日历，时间及稍后提醒继续使用时钟 |
| 整理与位置 | 整理使用列表排序图形；桌面位置保留侧栏布局图形 |
| 查看更多任务 | 向右箭头表示进入任务，向下箭头只用于展开选择 |

沿用三主题的颜色、24px 图形网格、统一描边和上轮补齐的悬停说明。共用带文字图标按钮让应用专属动作直接可读，常见的编辑、关闭、更多仍使用约定图形及悬停提示。

验证：桌面 / internal 现有测试、Go vet、MyGo UI vet 通过；macOS arm64 打包与严格签名验证通过；Windows amd64 / arm64 构建及资源验证通过。Computer Use 在独立内存实例中检查三主题、缩窄窗口、任务操作文案和标签显隐切换，截图在忽略目录 `build/results/icon-ui-20261018/`。未进行 Windows GUI 实测。
