# 快速添加快捷键恢复（2026-10-17）

Sidelet 0.2.0 build 29。

## 原因与修改

本机仍运行 `/Applications/Sidelet.app` 的旧 WebView 版 0.1.0 build 25（bundle ID `io.sidelet.spike`）。新旧版争用 `Control + Shift + Space`，新版 Carbon 独占注册返回 `OSStatus=-9878`。

设置页新增“重试快捷键”。注册失败保留错误；占用解除后原进程即可重新注册，成功显示“快捷键已启用”。不自动轮询，不修改其他应用快捷键，也不强制退出其他实例。退出后的回调保护和注册去重保持有效。

## 验证

- 全量 Go 测试、race、vet 和 macOS arm64 构建通过。
- UI 回归覆盖重试仍失败、再次成功、错误清除和成功状态显示；既有测试覆盖重复注册、注销与旧回调失效。
- 真实 Mac：旧版运行时初次注册和手动重试均失败；通过正常退出关闭旧版后，同一个新版进程点击重试成功。由此确认本次占用来源，而非推测 MyGo 升级导致。
- 恢复后的快速添加窗口入口与 Escape 取消通过。Computer Use 的按键工具不能发送真正的系统全局快捷键，本轮不把“注册成功”称为后台按键触发验收。
- 仅使用隔离 SQLite 测试资料。旧版正常退出，未删除应用或个人数据；测试新版也已退出，未替换 `/Applications/Sidelet.app`。

证据：`build/results/shortcut-recovery-20261017/app.log`、`recovered-ui.txt`。
