## 图标资源校验

原资源与本机 MyGo 渲染结果存在极小像素差异，导致严格逐像素测试失败。使用现有 `scripts/prepare-icons.go` 重新生成图标后通过；未修改 SVG 图案、测试阈值或跳过测试。

128/256/512/1024px 图像分别有 3/2/4/5 个像素变化，RGBA 单通道最大差值为 1（8 位色阶）；32px 托盘图标未变化。这解释了测试失败，但不足以单独确定差异来自哪个平台或编译器设置。

重新生成命令：

```sh
bash scripts/go.sh run scripts/prepare-icons.go
```
