# 主窗口草稿与表单体验

2026-10-23，build 40。继续使用 Go + MyGo，在现有三主题布局上修正表单状态与操作反馈。

## 行为

- 新建任务写到一半去编辑已有任务，暂存新建备注、日期（包括没填完的分段）、提醒、临时选项和展开状态。新建标题、重要程度和固定选项继续独立保存。已有任务保存、取消、Esc、切换筛选或被完成后，恢复原新建内容；连续编辑不同已有任务不会覆盖这份新建草稿。
- 切换列表筛选不会清空新建表单；再次点击当前已选筛选不会取消编辑。再次点击当前编辑任务的标题 / 编辑按钮只重新聚焦，不重载内容或刷新版本号，因此不会绕过并发修改保护。
- 主窗口备注与卡片一致，支持 Command+Enter / Ctrl+Enter 提交。普通 Enter 仍换行，中文组合输入期间不提交；日期校验、任务版本与持久化流程沿用原逻辑。
- 错误提示出现时保持表单节点身份，避免错误横条插入后备注框失去焦点；可以修改后直接再次快捷提交。
- 备注标签右侧显示当前平台的快捷键。折叠更多选项后显示已选重要程度、日期、提醒及临时状态；不完整日期明确显示“日期待完善”，不会被当作有效时间。

草稿只保存在当前主窗口内存中，不持久化到 SQLite；关闭 / 重建窗口或退出应用仍清空未提交内容。切换到另一条已有任务仍进入该任务的编辑状态，本轮不提供多任务编辑草稿管理。
