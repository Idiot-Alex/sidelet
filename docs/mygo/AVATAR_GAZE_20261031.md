# 精灵视线跟随 · build 49

开启桌面精灵后，双眼平滑看向鼠标所在位置。虹膜、瞳孔与高光一起移动，眼白裁切移动范围；身体、拖动把手和菜单入口保持原有行为。设置预览、Dock、托盘及网站图标仍为静态图。

## 实现与资源边界

- Mac 使用 MyGo 的 `Screen.CursorScreenPoint()` 与窗口屏幕坐标，两者均为左上原点的逻辑坐标。
- Windows 用 `GetCursorPos` 与 `GetWindowRect` 的物理像素坐标计算相对方向，再按精灵尺寸归一化，避免跨不同 DPI 屏幕直接相减逻辑坐标。
- 水平/垂直最大偏移为 SVG 坐标的 3.2/2.3，近处移动较小，远处逐渐饱和；约 70ms 的指数平滑，移动时最多 30Hz 更新。
- 静止且视线到位后只以 10Hz 读取坐标，不持续重绘。隐藏、关闭、退出时取消定时器；带代次检查的主线程回调丢弃隐藏前已排队的更新，重新显示时恢复。
- 原 SVG 加入眼白标识和眼球层边界，从同一素材延迟派生并缓存身体、移动眼球、遮罩三个 SVG。每帧仅改变绘制平移，不解析 SVG 或创建整幅图片；眼球绘制限制在面部范围，保留透明背景。
- 沿用“显示侧栏动漫头像”开关；无需启用 Windows CI。

## build 50：远距离响应优化

用户反馈：鼠标远离精灵时，眼睛转动不明显。

原映射用鼠标向量的总长度归一化，横向距离很远时，会一起压低纵向变化；原水平/垂直最大移动也只有 3.2/2.3 SVG 单位。现在分别映射横、纵两个方向，使用软饱和曲线（距离为 6 倍精灵宽度时达到该轴一半行程），最大行程调为 4.6/3.4，最后统一限制斜向移动范围。眼白遮罩、平滑过渡、更新频率和隐藏停用逻辑保持原样。

例如鼠标在精灵左侧 1400 DIP 处、上下移动 360 DIP，实际 54 DIP 图案内的眼球纵向行程从约 0.25 DIP 提高到 1.00 DIP，约为原来的 4 倍。这是映射计算与回归测试结果，不是帧率或性能增幅。

新增回归覆盖远距离纵向响应、沿距离方向移动仍有变化、中心和限幅边界连续、移动方向不反转。相关 `-race` 测试通过，五方向渲染图已检查，无瞳孔越界。Mac 与 Windows 使用同一映射。

本轮证据位于 `build/results/avatar-gaze-distance-20261031/`；build 50 测试包沿用上一节的三种平台命名，将文件名中的 build49 替换为 build50。
