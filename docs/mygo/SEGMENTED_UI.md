## 本轮改动

截止输入改为“年／月／日 时：分”五个独立分段，移除主字段右侧的时钟图标。空日期显示弱化的本地日期 / 时间提示，不产生截止时间；字段空余区域及 Alt + ↓ 仍可打开中文日历 / 时间弹层。分段支持数字输入、输满后自动跳转、左右移动、Tab / Shift + Tab、上下步进、复制 / 剪切 / 粘贴、单段删除和全选清除。粘贴完整有效日期时兼容旧 ISO 格式。

部分填写、非法日期与 DST 不存在的本地时间始终是草稿，保存时报错，不归一化或覆盖已有任务；步进日期按目标年月限制天数。未改变显示时间仍保留原始秒 / 毫秒，清空所有分段时关闭提醒。Tab 事件立即结束本次数字输入序列，避免连续事件在下一帧之前返回原分段时拼接旧数字；失去日期字段焦点也清空序列。

头部操作与卡片操作的文字采用明确的 16 px 行框，与图标居中对齐；复用正式主题字体，不替换设计方向。按钮、输入、备注和选择器的键盘焦点轮廓为主题色、2 px 宽、3 px 间隔，鼠标点击不绘制键盘轮廓。截止字段的各分段共享外部轮廓。

展开表单修正提醒、提示与临时选项间距，避免列间距与额外 margin 重复计入。最终同尺寸 Mac / 纸色截图中，新建表单底边与参照约差一个截图像素；窗口截图有轻微缩放差异，这不作为逐像素一致证明。

侧栏完成按钮采用正式的方形圆角。标题按正式 `reveal` 动画在 200 ms 内从右侧 8 px 淡入，使用 CSS `ease-out` 对应的 cubic-bezier(0,0,.58,1)。标题在固定宽度的裁剪容器内移动，文本测量与省略宽度不随动画改变；把手、预览点击区、原生输入面板和卡片锚点保持稳定。收起立即停止标题动画，系统“减少动态效果”开启时直接显示，没有新增常驻刷新。
