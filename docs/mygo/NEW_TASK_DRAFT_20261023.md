# 新建任务草稿自动保存

2026-10-23，build 43。

主窗口新建任务的标题、备注、重要程度、固定选项、截止时间、提醒和临时状态现在自动保存到 SQLite。备注 / 选项的展开状态以及没填完的日期分段一并恢复；关闭再打开主窗口或正常退出后重启，继续填写原内容。切去编辑已有任务时，保存的是暂存的新建内容，不会把已有任务的未提交修改混入。

## 保存与失败处理

- 输入停止 600 ms 后写入独立草稿行，连续输入会重新计时；无变化不写入，不重写任务列表，也没有新增后台轮询。输入法尚未确认的组合文本不落盘。
- 隐藏 / 关闭主窗口、正常退出前立即保存，不必等待防抖。失败会保留窗口和输入，在固定可见区域显示重试入口；取消退出不会提前停止托盘、快捷键、提醒或计时器。
- 添加任务与清除该草稿属于同一 SQLite 事务。任务校验或写入失败保留草稿；成功后清空表单和持久草稿。快速添加不会消耗主窗口草稿。
- 清空内容并恢复默认选项会删除草稿。允许保存未填完的日期和超过任务长度限制、尚待修改的文本；草稿 JSON 上限 1 MiB，超限保留界面输入并提示，避免阻塞其他任务保存。

只持久化主窗口的新建草稿；已有任务编辑、浮动卡片编辑及快速添加草稿不跨应用重启恢复。`-memory` 仅支持本进程内重开窗口。强制终止仍可能丢失最近 600 ms 内尚未写入的输入，正常关闭会立即补写。

## 数据库兼容

SQLite `user_version` 从 1 事务升级到 2，新增单行表 `native_new_task_draft`；已有任务、资料标识和提醒回执保持。领域资料 JSON 的 `schema` 仍为 2，草稿自身版本为 1。启动后的任务写入与草稿使用同一事务；草稿单独更新只修改新表。

build 42 及更早版本会拒绝打开升级后的库。升级前按现有规则退出并备份整个资料目录；回退旧应用时需要对应升级前的完整备份，不能用旧程序继续写入新版数据库。本轮测试只使用合成资料目录。
