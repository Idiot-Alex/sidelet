# 当前 MyGo 与正式 WebView 内存短测

2026-10-15，Apple M3 Max，macOS 26.6.2。两版以 Launch Services 独立启动，使用三条相同标题、备注、重要程度和固定状态的合成任务，Mac 主题、1120×800 主窗口。正式参照使用 SQLite 测试库副本；MyGo 使用 `-memory`，不包含 JSON 持久化开销。不是纯渲染器等条件基准，也不是完整功能等价后的迁移收益。

| 场景 | MyGo RSS / footprint (MiB) | WebView RSS / footprint (MiB) | footprint 降幅 |
| --- | --- | --- | --- |
| 主窗口启动后 | 121.73 / 49.24 | 272.52 / 328.86 | 85.0% |
| 三次编辑保存后 | 123.50 / 50.78 | 288.06 / 118.33 | 57.1% |
| 隐藏主窗口后 | 123.77 / 64.70 | 288.24 / 130.94 | 50.6% |

方法：前两段各预热10秒、每5秒采样、持续30秒（7点）；隐藏段预热15秒、持续45秒（10点）。表中为中位数。按相同 resource + jetsam coalition 汇总主进程、WebContent、GPU、Networking；两版 coalition 分离，全程分别为1个与5个进程。没有强制GC或主动结束WebKit。隐藏为 UI“隐藏窗口”，不是退出或销毁主窗口；没有打开浮动卡片。

启动阶段 WebView footprint 约329 MiB，末点 GPU 单进程约215 MiB，后续操作后整体降至118 MiB。不要用启动高值推算长期节省85%；本次操作后及隐藏状态低约49–57%。隐藏后两版 footprint 都比编辑后略高，本次观察窗内未回落；短测未定位增长来源，也不能判定泄漏。
