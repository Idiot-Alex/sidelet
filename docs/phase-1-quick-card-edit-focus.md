# 卡片内编辑与主窗口焦点

日期：2026-10-07。macOS 本地预览构建 21。

## 行为

短任务与长任务都在浮动卡片中编辑标题和备注。保存成功或取消后，回到同一张卡片的阅读状态，并保留键盘操作；卡片不会因鼠标离开自动收起。此时可继续编辑、完成、延后，或用关闭按钮 / Esc 退出。保存失败仍保持编辑和原输入。

进入编辑、保存、取消不会打开主窗口。完整任务属性仍在“我的任务”中编辑，用户通过 Dock、菜单栏等入口主动打开。卡片编辑不自动跳转至完整编辑器。

## 修复

- 编辑结束使用专门的 `quick-edit-finish` 消息，在当前卡片切回 `KeyboardActive`，而非立即退出整个输入会话并恢复前台应用。关闭卡片时才恢复此前应用。
- 保存前捕获任务会话代次，结束消息校验窗口、代次、编辑状态与待准备状态；共用弹窗仍校验当前视图和弹窗代次。旧保存回复不会结束后来打开的任务编辑，快速添加也不会受到旧消息影响。
- 退出编辑后聚焦卡片本身，让后续快捷键继续作用于卡片，不保留已移除的输入框焦点。
- macOS 只捕获可见的自有键窗口。恢复自有窗口时不重新显示已经隐藏的窗口，也不因空的自有焦点记录激活主窗口。旧逻辑会对已隐藏的窗口执行 `makeKeyAndOrderFront`，存在重新打开主窗口的路径。
- “完成整理” / 整理中的 Esc 是显式返回操作：整理开始时记录主窗口是否显示，结束时按该记录主动返回，避免焦点保护改变已有整理流程。普通隐藏、切换窗口会清理这条返回状态。
