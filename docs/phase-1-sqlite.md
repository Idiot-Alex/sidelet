# macOS · SQLite 与基础任务管理

状态：**开发版已实现并完成本机功能验证；P0 原生验收仍待完成**。更新日期：2026-10-05。

用户要求先做 M3 Mac 版本，并在上一轮原生验收状态讨论后明确要求先推进下一步。本轮按这一指示接入 SQLite 和真实任务管理；不修改 Revision 4 原文，也不把此前缺少证据的鼠标、多屏和 Space 项标为通过。

## 已实现的行为

正常启动使用真实数据库，首次为空，不创建样例任务。我的任务窗口支持标题、备注、截止时间、重要程度、临时标记、待办 / 已完成 / 全部筛选，以及新增、编辑、删除、完成和恢复。关闭主窗口仅隐藏，菜单栏可以再次打开。

桌面展示需手动固定，任务内容与展示关系分开保存。取消固定不删除任务；完成和 Snooze 保留 Stack 归属和顺序。Quick Card 的标题和备注编辑同样写入数据库，未提交的新内容不会提前发布给其他窗口。失败时显示中文提示并保留草稿，成功确认后才退出编辑；提示限定到发起操作的窗口。

完成立即保存，桌面保留 800ms 反馈，5 秒内可撤销。临时任务在撤销期结束后自动删除；启动时清理已完成的临时任务，符合 Revision 4 的重启规则。Undo 会话状态不写入数据库。Snooze 支持 30 分钟、1 小时和本地下一自然日 09:00，不更改截止时间、归属或顺序。主窗口可以提前恢复暂时隐藏的任务。

Stack 保存屏幕 UUID、左右边缘、归一化中心位置及紧凑 / 标准 / 宽松密度（40 / 44 / 56px）。目标屏幕缺失时回到主屏并保存有效位置；待处理的旧屏幕重映射不会覆盖后来保存的密度和偏移。每个 Stack 继续共用一个 WebView。

## 数据与运行方式

默认数据库为 `~/Library/Application Support/Sidelet/sidelet.sqlite3`。`-data-dir` 指定独立资料目录，`-main` 强制打开任务窗口；无任务时自动打开。数据库启用 WAL、完整同步、连接级外键和 3 秒锁等待。SQLite 驱动固定为 `modernc.org/sqlite v1.60.1`。

第一版事务迁移创建 `todos`、`desktop_presentations`、`edge_stacks`、`edge_stack_items`、`reminders` 和 `schema_migrations`，同步记录 `PRAGMA user_version=1`。主键、外键、唯一归属和展示一致性约束防止悬空任务关系。迁移失败回滚；更高版本、不一致历史和损坏数据库报错退出，不重建覆盖原文件。`reminders` 暂为后续提醒功能预留，没有通知调度。

数据库操作在串行后台控制器中执行，原生窗口操作与状态发布在主线程执行。只有提交成功的快照发送给各窗口，每次任务操作使用请求 ID 确认成功或失败。没有新增任务轮询；完成反馈、Undo、Snooze、截止时间状态和临时清理使用对应截止时间的一次性定时器。

同一资料目录的实例锁在数据库打开之前取得，重复启动显示已有任务窗口，避免第二实例的启动清理影响当前会话。首次安装创建一个右侧 Stack，不填充假任务。

```sh
npm run build:macos
open "build/bin/Sidelet Spike.app" --args -main

# 独立测试库
open -n "build/bin/Sidelet Spike.app" --args -main \
  -data-dir "$PWD/build/results/my-test-data"

# 旧的可丢弃原生验收场景，不打开用户数据库
open -n "build/bin/Sidelet Spike.app" --args -spike -main
open -n "build/bin/Sidelet Spike.app" --args -spike -two-stacks
```

`-spike` 与 `-data-dir` 不可同时使用；`-two-stacks` 只用于显式假数据模式。真实键鼠验收启动器已加 `-spike`。应用包和可执行文件暂时沿用既有 Spike 文件名，避免破坏现有采样和验收脚本。
