# macOS · 桌面任务排序

更新日期：2026-10-05。状态：实现完成，数据与主窗口拖动已验证；桌面 NSPanel 的真实鼠标拖动仍保留未验收记录。

## 使用

在“我的任务”或菜单栏选择“整理桌面”。桌面标签展开成排序列表，拖动左侧手柄，在插入线处松手即可保存。平时标签保持锁定，普通点击仍用于查看和快速编辑。点击“完成整理”或按 Esc 退出；拖动中按 Esc 先取消这次拖动。

桌面仍最多直接显示八条任务。“全部任务”或 `+N` 打开主窗口中的完整桌面顺序列表，可整理原本收在溢出区的任务。列表按 Stack 分组，拖动限定在同一个 Stack 内。也可以聚焦手柄后使用 Option + ↑ / ↓ 连续调整；保存后保持手柄焦点。长列表拖动接近可滚动区域边缘时自动滚动，只在拖动期间运行动画帧。

从桌面切到主窗口保留整理状态。切换到其他程序、安静模式和屏幕变化会退出整理并取消尚未提交的拖动。重启默认为锁定状态。当前增量只调整任务顺序，不移动整个 Stack，也不迁移任务到其他 Stack。

## 保存规则

拖动过程中显示插入位置，不提前改写已保存顺序。松手后通过现有请求确认机制提交；提交成功再更新所有窗口，失败显示提示并保持原顺序。拖出列表、指针取消、窗口失焦和布局变化取消未提交的拖动。

`reorder` 操作包含 Stack ID、原可见顺序和目标顺序。事务内核对当前完整可见成员，拒绝缺项、重复、非固定任务、其他 Stack 的任务和过期顺序。拖动期间任务完成、隐藏或其他窗口已经调整过顺序时，旧请求不能覆盖新状态。

只交换可见、未完成任务所占的 `edge_stack_items.sort_order` 槽位；已完成和 Snooze 任务的数值保持不变。任务标题、备注、截止时间、状态、时间戳、展示关系、Stack 布局和已有 Undo 状态不因排序改动。不需要数据库迁移，现有 v1 数据直接使用。
