# Phase 1：macOS 完整流程回归

日期：2026-10-05。使用 M3 Mac、macOS arm64 开发包与独立资料目录。目标是验证任务、桌面布局、提醒、设置组合使用时的数据一致性；不将此前未完成的 P0 人工验收视为通过。

## 可重复运行

```sh
npm run test:regression
npm run build:macos
```

`test:regression` 运行前端静态检查和测试、全部内部 Go 包及控制器的 race 测试、vet，并在 macOS 上运行已有原生窗口测试。需要可用的 macOS 图形会话。真实应用流程的操作记录另存于 `build/results/regression-native-20261005/`，不会写入正常任务库。

新增 `internal/integration/lifecycle_test.go`，使用真实 SQLite 和设置文件，只有系统通知服务使用可控替身，不修改系统时钟，也不需要等待 30 分钟。两个串联用例已纳入 Mac 与 Windows 构建脚本：

1. 创建默认不固定的任务 → 手动固定 → 排序 → 移动整组 → 延后 30 分钟 → 完成与撤销 → 权限拒绝时保留到期提醒 → 修改新任务组默认值 → 重启保留现有布局 → 允许后补发 → 完成、撤销、重启不重复通知 → 临时任务重启清理 → 关闭提醒。
2. 系统接受通知后，SQLite 凭据写入失败 → 关闭并重新打开数据库 → 读取系统现有记录补写凭据，避免重复发送；任务编辑失败时，内容、布局和提醒生成保持原值。

## 真实应用流程

两条任务通过真实主窗口创建。测试目录：`build/results/regression-native-20261005/data/`。

| 项目 | 证据 / 结果 |
| --- | --- |
| 新任务默认不固定、显式固定 | Regression A 创建后未固定，点击固定后出现在桌面；Regression B 在创建时明确勾选固定 |
| 桌面排序 | Option + ↑ 将 B 移到 A 之前，SQLite 槽位为 B=10、A=20 |
| 整组移动 | 手柄方向键从右侧移到左侧并向下，Enter 保存，offset≈0.44965；重启保持 |
| 延后 | Quick Card 选择 30 分钟，DueAt 不变，SnoozedUntil 与 RemindAt 一致；主窗口可“现在恢复” |
| 完成 / 撤销 | B 完成后在 5 秒内撤销，回到原顺序 |
| 保存失败 | 仅在测试库对 B 注入更新失败；草稿保留、提示失败，各表与操作前完全一致；移除故障后再次保存成功 |

自动化工具对被动 NSPanel 的点击未稳定打开卡片，因此卡片测试使用项目已有 `-interaction-test` 与 `MacInteractionFixture` 的显式键盘入口，日志标记 `source=fixture-request`。后续按键、卡片操作使用真实 UI。此结果不证明真实鼠标点击或系统全局快捷键交付。

系统权限只操作 Sidelet；测试前后均为允许。正常资料目录没有创建样例任务。故障注入触发器清除后再进行后续验收。

- 真实桌面鼠标穿透、直接拖动与边缘捕获、外部输入焦点、多屏 / Spaces / 全屏组合仍按 P0 记录待验收。原生测试通过只能证明对应断言，不能替代真实设备操作。

- 实际休眠唤醒、修改系统时间、注销后自动启动没有在本轮操作；时间跳跃与登录注册的已有证据见对应阶段文档。

- Windows 仍没有原生交互与系统通知验收。
- 此版本仍是本地临时签名开发包；正式发布名称、图标、签名、公证和安装包尚未制作。
