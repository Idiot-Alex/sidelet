## 更多与删除

“更多”在任务行内展开，删除保留二次确认。展开后焦点进入“删除任务”，进入确认时默认聚焦“取消”；确认按钮需要再明确操作。支持确认区 Tab / Shift + Tab、上下方向键以及 Esc 关闭后返回更多按钮，点击或聚焦外部、切换筛选、进入整理及窗口失焦时收起。保存失败保留原确认状态和错误反馈。
