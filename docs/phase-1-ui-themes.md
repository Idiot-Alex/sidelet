# Phase 1：UI 整理与主题切换

2026-10-05，macOS Apple Silicon，0.1.0 构建 4。按用户选择，默认采用精致 Mac 风格，同时提供可保存的温暖纸色和深色石墨主题。

## 使用与界面

主窗口右上角的设置按钮、菜单栏“设置…”或 Command + , 打开设置，进入“外观”后直接点击主题预览。选择自动保存，无需重启；任务窗口、设置页、桌面标签、整理控件、快速卡片和 macOS 主窗口标题栏同步更新。

- 精致 Mac：柔和灰绿底色、白色内容面、系统字体。
- 温暖纸色：暖纸底色、棕色强调、衬线标题；正文保留易读的系统字体。
- 深色石墨：石墨底色、浅色文字和低饱和绿色强调；日期输入、下拉框和快速编辑表单也使用深色控件。

任务列表放到左侧主区域，右侧保留新增 / 编辑表单；截止时间、提醒、重要程度和临时任务收进可展开的更多选项，编辑已有任务时自动展开。桌面位置单独折叠。统一了页头、间距、按钮、焦点样式、空状态和重要程度标记。设置与任务页相互切换时回到页面顶部，未保存的任务草稿保留。

主题仅给可见内容绘制背景。html、body、#app 和原生 Stack 空白区继续透明，细窄标记、悬停展开、原生命中区域及键盘行为保持原方案。

## 实现与保存

`frontend/src/theme.css` 提供共享语义颜色、标题字体和圆角变量；所有任务与设置组件使用同一套变量，未增加 UI 框架、字体下载或其他运行依赖。

`settings.json` 增加 `appearance.theme`，取值为 `mac`、`paper`、`graphite`。偏好文件版本仍为 1，SQLite 版本仍为 2。读取旧设置时缺少该字段会补默认 Mac 主题，并保留原有启动和桌面默认值。未知主题会被拒绝；写入失败仍沿用原有偏好回退和文件保护机制。

偏好保存成功后通过 Wails 事件发布给全部 WebView；每个窗口 ready 时请求最新偏好，覆盖重新创建窗口的情况。macOS 仅对主窗口设置 NSAppearance 和标题栏背景，透明浮层不调用此接口。Windows 内容层共享主题，标题栏继续由系统管理，本轮没有做 Windows 实机验收。

## 验证

证据位于 `build/results/ui-native-20261005/`。

- `regression.log`：前端静态检查无错误 / 警告；19 项前端测试；Go 竞态测试及 vet；29 项 macOS 原生命中 / 焦点断言通过。
- `internal/settings/settings_test.go`：新增旧设置兼容、三主题保存 / 重启恢复和非法主题不覆盖验证；设置测试共 4 项。
- 原生透明渲染测试现在加载共享主题 CSS，依次检查三套主题，共 16 项断言通过。每套主题空白 alpha=0、卡片 alpha=1、空圆角 alpha=0。该测试渲染自己的 WKWebView，不截取用户桌面。
- 实机通过应用 UI 切换三套主题，确认设置页、任务页、浮动卡片的真实样式；纸色主题退出 / 重启后仍保留。深色快速编辑输入框与 Esc 取消正常。
- 独立测试库中验证新增任务、固定到桌面、编辑、完成 / 撤销、切换主题保留未提交标题及备注、截止时间编辑后保留原毫秒值、更多选项与桌面位置展开、空库引导及其输入焦点。
- 真实卡片检查使用项目已有的 `-interaction-test` 键盘入口夹具，不将其计为全局快捷键的物理输入验收。图片中的透明区域可能被截图格式合成为白色；透明性以原生 alpha 测试为准。
- `package.log`：最终构建、签名和 DMG 校验通过。最后的下拉框样式微调另做了实际窗口检查，记录于 `settings-lower.jpg`；其余截图来自本轮相同功能的构建 4 迭代。

示例任务全部位于独立测试目录。正常任务库在更新前做了备份，结束时逐表核对，用户原有任务及固定关系保持不变。旧应用保存在 `Sidelet-build3.app`。主应用已恢复正常资料目录，使用精致 Mac 主题。
