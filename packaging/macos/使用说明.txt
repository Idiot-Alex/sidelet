Sidelet {{VERSION}} · MyGo 原生预览版
适用于 macOS 13 或更新版本，{{PLATFORM}}。

安装
1. 退出旧 Sidelet 和 Sidelet MyGo Lab。
2. 把 Sidelet.app 拖入 Applications（应用程序）。
3. 从“应用程序”打开 Sidelet。

数据
当前应用使用 SQLite 持久化，沿用 MyGo 原有资料目录：
~/Library/Application Support/SideletMyGoLab
数据库：sidelet-native.sqlite3。首次启动自动导入同目录 profile.json 并保留原文件，后续只读取 SQLite。
请退出应用后备份整个资料目录（含可能存在的 WAL 文件）。
旧 WebView 的 ~/Library/Application Support/Sidelet/sidelet.sqlite3 不会删除或覆盖，当前版本尚不支持自动导入。
为保留已有 MyGo 授权，系统应用标识仍为 io.sidelet.mygo-lab；系统列表可能暂时显示旧名称。

使用
• 在主窗口创建任务，勾选“固定到桌面”后显示侧边标记。
• 卡片可就地编辑；Command+Enter 保存备注，Esc 取消。
• 快速添加：Control+Shift+Space。若快捷键被占用，先退出其他 Sidelet 实例，再到设置点击“重试快捷键”；也可用菜单栏入口。
• 提醒需设置截止时间并勾选“提醒我”，且允许系统通知；应用需在后台运行。
• 菜单栏退出才会停止后台运行。仅使用当前 Sidelet 的设置管理登录启动。

限制
本包为本地 ad-hoc 签名，未 Developer ID 签名或公证。
Windows 通知、多屏 / Spaces、真实悬停跨窗、旧数据导入、多任务组与部分键盘操作尚未完成验收。
