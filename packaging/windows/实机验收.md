# Sidelet Windows 实机验收

版本：{{VERSION}}；架构：{{ARCH}}。初始状态：所有项目待验收。

记录电脑架构、Windows 版本与构建号、显示器数量、缩放比例、输入法、是否启用勿扰模式，以及 ZIP 校验值。结论请写“通过 / 失败 / 未测”，失败时附操作步骤。不要把空白记录算作通过。

## 准备

1. 比对 ZIP 的 SHA-256，完整解压到普通用户可写目录。
2. 确认包架构匹配机器。右键 `Sidelet.exe` 查看属性，核对图标、产品 Sidelet、产品版本和四段文件版本。
3. 完全退出其他 Sidelet 进程，在 PowerShell 中进入解压目录，运行：

   ```powershell
   .\Sidelet.exe -main -data-dir "$env:TEMP\Sidelet-Windows-Acceptance"
   ```

4. 独立测试目录若已有上次数据，改用新的目录名称；不要覆盖或删除日常资料。
