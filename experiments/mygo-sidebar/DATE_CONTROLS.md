# 日期控件与内容高度 · 第十一批

2026-10-10。继续对齐正式 Sidelet，在全原生实验中补中文日期控件，并校准表单和阅读卡片高度。**没有引入 WebView；完整 UI 一致性仍未验收。**

## 日期与时间

截止时间显示为本地 `2026/10/31 16:30`，日历显示中文年月、星期与日期，时间字段使用中文辅助标签。文本输入继续兼容旧 ISO 格式，也接受斜线和中文日期。

日历支持点击、方向键、Page Up / Down、Home / End、上个月 / 下个月及 Enter / 空格选择。月份切换在目标月截断月底日期，例如 1 月 31 日切到平年 2 月 28 日，闰年切到 29 日；不会因时间归一化跳过月份。日历用 UTC 表示民用日期，提交时才按任务的本地时区解释时分，拒绝夏令时中不存在的时间。

小时 / 分钟可输入或用上下键调整，各自在 0–23 / 0–59 范围循环。非法值保留弹层和草稿，显示错误；选择日期不提交任务。两级 Esc 分别关闭日历和日期弹层，保留外部任务编辑。清除日期关闭提醒；确认未改动的已有时间仍保留原始秒 / 毫秒及歧义时间对应的精确时间戳。

## 表单与卡片

明确标题 / 备注标签、固定选项和表单操作按钮的高度，去掉 MyGo 默认文字行高额外占用的空间。Mac 主题的同尺寸截图中，正常新建表单底边约为 475 / 474 像素；截图有轻微缩放差异，不将这一局部比较当作逐像素一致证明。

阅读卡片采用内容列上一帧的实际排版高度，包含备注换行、重要程度 / 日期换行和错误信息，再加页头、操作区与边框；保持 160–390 px 限制，长内容滚动，编辑仍为 390 px。内容、主题或宽度变化后先等待新布局，避免沿用旧尺寸。缓存内容标识并使用整数节点键，避免每帧将完整备注格式化成键。布局稳定后停止调整尺寸，没有新增持续轮询。

最终实机流程中的同一基准任务由旧估算 191 px 改为 188 px；编辑为 390 px，取消后回到 188 px，x=1100 / y=301 未变，原标题保留。这是原生排版结果，仍不证明与 WebView 字体度量完全相同。

## 尚未一致

WebView 的 macOS 日期字段是系统分段控件；当前原生为文本框与中文日期 / 时间弹层，结构和部分键盘 / 焦点样式仍不同。标题、预览细节、字体度量、卡片滚动和动画仍需继续对照；新几何的后台鼠标交接与多屏不属于本轮已验证范围。整体差异见 [UI 对齐记录](UI_PARITY.md)，`overallParityVerified` 保持 false。
