# MyGo 与正式 Sidelet UI 对齐

2026-10-07。用户确认以**正式 Sidelet 的完整界面**为准，包括任务页、设置、三种主题、侧栏、任务卡片和快速添加。继续保留全原生 `ui.View`，不为对齐界面引入 WebView。

当前已完成十二批界面与共享业务对齐实现，**尚未通过“完全一致”验收**。不能将旧实验的简化 Web 页面当作正式 UI，也不能将源码摘要、主题同步或功能测试通过当作视觉一致的证据。

## 唯一参照与同步

参照仓库中的 `frontend/src/theme.css`、`Icon.svelte`、`AppHeader.svelte`、`TodoManager.svelte`、`SettingsPanel.svelte`、`EdgeStack.svelte`、`QuickCard.svelte`、`QuickAdd.svelte`、`TaskOrder.svelte`、`geometry.ts`、`reorder.ts`、`StackDragHandle.svelte`。

`scripts/sync-mygo-ui.py` 从正式 CSS 提取三种主题参数，从 `Icon.svelte` 提取 16 个 SVG 路径，生成 `design/web-ui.json`。同时记录以上十二份文件的 SHA-256。构建先执行 `--check`；正式 UI 改动后必须审查对应原生实现，再重新生成。这个检查发现参照过期，不会自动转换布局，也不证明像素相同。

```bash
python3 scripts/sync-mygo-ui.py --check
bash experiments/mygo-sidebar/build-macos.sh
open -n build/bin/mygo-lab/SideletMyGoLab.app --args -native-main -main
```

## 明确未完成的差异

以下差异均为阻止整体验收通过的项，不能隐藏或算作已完成：

- 日期显示与中文日历已本地化，主输入改为年 / 月 / 日 / 时 / 分分段；仍需对照 WebKit 系统控件的弹层、提示值与辅助技术行为。
- macOS 登录启动、Dock 显示、启动窗口偏好与默认值保存已接入；登录启动的真实注销 / 再登录与已签名发行包尚未验收。当前仍为单任务组，新任务组默认值不会改动已有布局，多组创建尚未迁移。Windows 系统通知适配尚未迁移，当前仅 macOS 可发送。
- 快速添加的解析、快捷键注册和焦点恢复已接入，但真实全局按键到达、实际中文输入法候选确认、多屏 / Spaces / 全屏打开仍未验收；本机正常快捷键已被其他应用占用，冲突提示通过。
- 持久模式已保存任务、主题、位置和提醒回执，但使用独立 JSON，没有正式 SQLite 的迁移 / 导入和备份恢复 UI；启动资料损坏时保留原文件并拒绝启动，错误写入日志。主列表筛选栏提示“自动保存在本机”；`-memory` 显示“合成任务 · 不保存”，设置页保留独立资料说明。系统通知权限仍属于独立实验标识。
- 空列表插画 / 文案 / 聚焦入口已补齐；加载 / 保存中 / 错误状态仍需逐状态补齐并截图验收；排序与溢出已接入，仍需与正式版逐像素校准；日期元数据已接入，字体与间距仍需校准。
- 卡片阅读高度已改为原生实际排版测量，仍需继续对照正式版字体度量与滚动行为；卡片锚点与关闭会话已按正式规则接入，标题展开动画已迁移并遵循减少动态效果；正常输入面板的真实鼠标跨窗口移动尚未重新验收。
- 整组移动的方向键预览 / Enter 保存尚未迁移；当前可用鼠标拖动，Esc / 失焦取消。
- 图标 / 操作文字行框、键盘焦点轮廓和展开表单间距已校准；字体度量、原生标题栏与预览细节尚未完成逐像素验收。主窗口已采用正式默认右侧与 35% 中心位置；无参数已进入完整原生应用，带显式参数的历史侧栏实验仍保持旧默认值。
- 新几何的透明绘制和悬停延时已有 headless 检查，不能据此声称正常非激活输入面板的后台拖动 / 多屏已重新实机验收。

## 第三批验证与证据（历史）

实验模块 47 项顶层测试通过，含子项共 66 项；构建检查正式 UI 参照、`go vet` 和 ad-hoc 签名验证通过，`go test -race` 通过。正式模块的 `go test ./cmd/... ./internal/...` 通过，涵盖存储、提醒和集成测试。宽泛的 `go test ./...` 会扫描 `build/results` 中不完整的历史源码快照而失败，原始日志保留；没有修改或删除这些历史证据。最终 Windows amd64 / arm64 交叉编译通过，仍不代表运行或通知验收通过。

新增检查覆盖三主题下日期 / 提醒 / 临时字段的加载、保存、清除和冲突保留，原始毫秒精度，非法日期与夏令时不存在的本地时间，嵌套弹层 Esc 与 1120 × 800 / 820 × 600 的日历边界，侧栏和卡片日期展示、卡片保存保留计划字段，以及临时任务按自己的完成时间清理、撤销和单次唤醒。提醒检查覆盖未授权不消耗、恢复后发送、失败重试、标题编辑不生成重复、稍后生成新提醒、过时发送 / 回执不消耗替代提醒、完成 / 撤销竞争和仅清理本次命名空间。

为保持原生二进制不依赖 SQLite，把提醒值类型移至 `internal/todo`，存储保留 `storage.Reminder` 类型别名；实验直接复用正式 `internal/reminder.Sync`，以不可变快照在串行后台工作线程协调系统状态，并在发送与清理前检查当前提醒代次。回执不增加任务版本，避免打断编辑。日期状态、稍后、提醒和临时清理共用下一次唤醒；监听系统唤醒 / 时钟变化并在应用激活时检查权限，没有常驻轮询。
