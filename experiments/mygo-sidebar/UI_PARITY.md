# MyGo 与正式 Sidelet UI 对齐

2026-10-07。用户确认以**正式 Sidelet 的完整界面**为准，包括任务页、设置、三种主题、侧栏、任务卡片和快速添加。继续保留全原生 `ui.View`，不为对齐界面引入 WebView。

当前已完成四批界面对齐实现，**尚未通过“完全一致”验收**。不能将旧实验的简化 Web 页面当作正式 UI，也不能将源码摘要、主题同步或功能测试通过当作视觉一致的证据。

## 唯一参照与同步

参照仓库中的 `frontend/src/theme.css`、`Icon.svelte`、`AppHeader.svelte`、`TodoManager.svelte`、`SettingsPanel.svelte`、`EdgeStack.svelte`、`QuickCard.svelte`、`QuickAdd.svelte`、`TaskOrder.svelte`、`geometry.ts`、`reorder.ts`、`StackDragHandle.svelte`。

`scripts/sync-mygo-ui.py` 从正式 CSS 提取三种主题参数，从 `Icon.svelte` 提取 16 个 SVG 路径，生成 `design/web-ui.json`。同时记录以上十二份文件的 SHA-256。构建先执行 `--check`；正式 UI 改动后必须审查对应原生实现，再重新生成。这个检查发现参照过期，不会自动转换布局，也不证明像素相同。

```bash
python3 scripts/sync-mygo-ui.py --check
bash experiments/mygo-sidebar/build-macos.sh
open -n build/bin/mygo-lab/SideletMyGoLab.app --args -native-main
```

## 明确未完成的差异

以下差异均为阻止整体验收通过的项，不能隐藏或算作已完成：

- 日期字段与日历已可用，但仍使用原生文本输入 / 时间步进器；文本显示 ISO 时间，日历月份与星期为英文，与 WebView 的本地化日期控件仍有外观差异。
- 安静模式尚未接入，按钮暂时禁用。整理桌面已接入，仍没有跨重启保存。
- Dock 显隐、登录启动、启动偏好、新任务组默认值和导出只补了布局，尚未迁移对应能力；这些控件禁用。登录状态明确显示“原型尚未接入”。Windows 系统通知适配尚未迁移，当前仅 macOS 可发送。
- 快速添加尚未识别自然语言时间，也未注册全局快捷键；从窗口 / 设置打开可用，时间识别控件禁用。
- 合成任务、主题、位置和提醒回执只在进程内存中保留，没有 SQLite / 设置持久化，也没有跨重启提醒恢复；退出清理本次运行的提醒。系统通知权限由 macOS 为独立实验标识保留。因此不显示“自动保存在本机”；保留实验说明文字。这些文案与正式版不同。
- 空列表插画 / 文案、加载 / 保存中 / 错误状态仍需逐状态补齐并截图验收；排序与溢出已接入，仍需与正式版逐像素校准；日期元数据已接入，字体与间距仍需校准。
- 卡片阅读高度目前由 MyGo 文本测量估算，需要继续对齐正式版实际测量高度；卡片锚点与关闭会话已按正式规则接入，展开动画仍未迁移；正常输入面板的真实鼠标跨窗口移动尚未重新验收。
- 整组移动的方向键预览 / Enter 保存尚未迁移；当前可用鼠标拖动，Esc / 失焦取消。
- 字体度量、控件焦点样式、原生标题栏与预览细节尚未进行逐像素校准。主窗口已采用正式默认右侧与 35% 中心位置；无参数的历史侧栏实验仍保持旧默认值。
- 新几何的透明绘制和悬停延时已有 headless 检查，不能据此声称正常非激活输入面板的后台拖动 / 多屏已重新实机验收。

下一批先处理以上界面与状态差异，并逐项接入共享业务；独立测试目录通过后才考虑迁移正式宿主。正式应用、安装包和用户任务数据库未替换。
