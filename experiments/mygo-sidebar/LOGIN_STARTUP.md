# MyGo macOS 登录启动

2026-10-09，第九批。独立应用 `io.sidelet.mygo-lab` 已接入 macOS 13+ `SMAppService.mainAppService`，使用 PureGo 调用系统框架，保持 `CGO_ENABLED=0`，不引入 WebView、Wails 或 SQLite。只管理 Sidelet MyGo Lab 的主应用登录项；不管理正式 Sidelet 或其他应用。

## 设置与状态

设置页的“登录 Mac 后启动 Sidelet”、检查状态与打开系统登录项入口已启用。开关读取实际注册状态，不用资料里的布尔值伪装系统状态；已开启、未开启、等待批准、系统未找到应用、读取失败分别显示。等待批准仍是已注册项，提供系统设置入口，不能宣称已可自动运行。

首次注册前，开发构建可能显示“系统未找到此应用”；仍允许尝试注册，不将此状态误当成永久不支持。系统查询失败时禁用开关，保留检查入口。只有正确标识的独立 `.app` 包可操作；裸二进制和其他应用标识拒绝操作。Windows 此能力仍明确显示不支持，仅编译通过。

启动、重新激活、返回前台、打开设置及手动检查时重新读取系统状态；检查不注册、不保存偏好。用户在系统设置撤销允许后，不会因重启应用而擅自重新开启。普通主题、Dock、启动窗口等偏好保存不会操作登录项；只有专用登录开关可以改变注册。

专用操作先读取当前系统状态，按需注册 / 撤销，再确认状态并保存独立资料。注册失败或资料原子提交失败时补偿回原注册状态，重新查询并恢复开关；资料不发布失败的偏好。补偿失败时显示实际状态和检查提示，不声称已恢复。实际系统错误仅写日志，界面不泄露文件路径。重复开启已注册项不重复注册。

## 登录时的启动方式

直接打开实验 `.app` 不带参数，现在进入完整原生应用，读取默认资料目录 `~/Library/Application Support/SideletMyGoLab`，不再进入历史的三任务侧栏演示。历史演示可继续通过 `-probe` / `-card` 等显式实验参数启动，`-hybrid` 仍单独选择混合模式。

SMAppService 启动主应用不附带实验参数。登录启动使用默认资料目录，不沿用 `-data-dir`、`-output`、`-memory` 或其他诊断参数；自定义测试目录用于验收，不是系统登录启动资料。移动应用前应在旧位置关闭登录启动，再从最终位置按需开启；当前仍是本地 ad-hoc 构建，没有发布或安装替换。

启动时先使用 Accessory 策略，建立菜单栏入口后应用已保存的 Dock 偏好，避免后台启动因 SDK 的 Regular 策略自动激活。MyGo `WasOpenedAtLogin()` 区分登录启动；关闭“启动时显示主窗口”时仅保留菜单栏和已固定任务，首次资料也不弹窗。普通首次手动启动仍显示窗口。开启偏好会创建主窗口；`-main` / `-main-hidden` 仍为测试覆盖项。退出不会撤销用户自己开启的登录项。

Computer Use 在正常适配、独立合成资料下实际开启 / 关闭登录项。临时将该测试资料目录改为不可写，触发注册成功后资料写入失败，确认真实系统注册被撤销、开关恢复关闭、资料字节未变；随后立即恢复目录权限。最终二进制复核错误只显示一次，检查清除错误，系统状态保持未开启，所有实验进程正常退出。未注销当前 macOS 会话。
