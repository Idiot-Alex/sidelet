# 三主题视觉校准 · 第十批

2026-10-09 开始，2026-10-10 完成。继续以正式 Sidelet 的 WebView 界面为参照，不增加 WebView，也不更换设计方向。**本批完成部分布局与状态校准，完整 UI 一致性仍未验收。**

## 修改

- 主窗口的 1120 × 800 改为内容区尺寸。此前 MyGo 将标题栏计入高度，与正式宿主的内容区定义不同；统一后再比较布局。
- 使用正式系统字体回退及纸色标题字体；统一按钮图标行高、桌面状态颜色、卡片次要按钮文字及悬停底色。卡片按钮原本已等宽，本批保留这一几何。
- 保存状态移到筛选栏右侧，窄窗口隐藏；持久模式显示“自动保存在本机”，内存诊断模式明确显示“合成任务 · 不保存”。
- 补齐空列表插画、文案和“写下第一件事”聚焦入口；入口不会直接创建任务。
- 长标题允许收缩，重要程度和截止时间按正式断点换行；备注、状态和操作按钮保持独立区域。
- 调整表单备注间距、设置卡片在窄窗口的边距、主题预览比例及说明行高、默认值分隔线、开关颜色和通知状态徽标。
