# MyGo 任务导出

2026-10-09。全原生设置页的 JSON / CSV 按钮已接通，复用正式版 `internal/exportdata` 的文件格式、CSV 转义和安全写入；不引入 WebView、Wails 或 SQLite。

## 行为与格式

点击按钮时在串行 UI 执行器中投影最近一次成功持久提交，随后在后台编码、打开 MyGo 原生保存对话框并写入。对话框默认定位下载目录，文件名为 `Sidelet-年月日-时分秒.json/csv`。取消不写文件；结果显示取消、失败原因或成功文件名与任务数。保存过程中禁用两种导出按钮及返回按钮，拒绝第二次并发导出。结果状态由服务保存，窗口视图重建后仍可显示；后台任务更新和提醒不被对话框阻塞。

导出全部未删除任务，包含已完成、未固定、稍后隐藏与尚未自动清理的临时任务，保持稳定 ID 和完整排序槽位。保存前的编辑草稿、拖动预览、安静状态、偏好、撤销记录、内部版本和系统提醒代次不进入文件。内存诊断模式使用当前已提交的合成任务，没有磁盘持久保证。

JSON 使用正式 `sidelet` 格式版本 1，实验应用版本标为 `0.0.1-mygo-lab`，包含任务和当前唯一桌面组的边缘、比例、密度。CSV 为 21 列、UTF-8 BOM、CRLF，时间为 UTC，备注的换行和引号经标准 CSV 转义；可能被表格解释为公式的文本前加单引号，JSON 则保留原始文字。

**数据边界：** 当前原生资料未记录任务 / 桌面组创建与更新时间、屏幕标识；JSON 时间字段为 0、屏幕标识为空字符串，CSV 对应单元格留空，界面明确说明，不编造历史值。导出不是完整资料备份，没有导入或正式 SQLite 迁移能力，不能据此认定业务与 UI 已完全一致。

## 写入保护

校验扩展名；按目录身份拒绝本资料目录及子目录，包括符号链接和大小写别名。完整数据先写到目标目录的临时文件，同步并关闭后原子替换；失败清理临时文件，不留下半份导出，不覆盖已有文件。文件系统路径错误在界面转为简短权限 / 空间提示，诊断细节写入日志。保护与原子替换直接复用已测试的正式导出模块。

新增 6 项顶层测试，累计 80 项顶层 / 含子项 138 项通过；三主题包含在子测试中。覆盖持久快照与隐藏顺序、中文多行文本、各任务状态、JSON / CSV 字段、表格公式防护、空列表、非法格式、对话框期间更新、并发拒绝、取消 / 失败后的重试、资料保护、错误提示、草稿保留及视图重建后的结果。race、vet、参照同步、macOS 构建 / ad-hoc 签名、共享导出模块测试通过。Windows amd64 / arm64 交叉编译通过，没有 Windows 运行或保存对话框验收结论。

Computer Use 在正常输入适配、独立空资料中创建三条合成任务，包含已完成、未固定和固定状态；实际保存 JSON / CSV，验证取消提示、拒绝向本资料目录写入、返回任务页仍保留未提交标题。导出文件与持久任务逐字段核对，中文引号、多行备注、CSV 公式防护符合预期；取消 / 资料保护前后的资料文件字节一致。稍后隐藏、临时任务和对话框期间更新由自动测试覆盖，本轮实机未另造这些状态。
