# MyGo 快速添加

2026-10-09。全原生入口复用正式 `internal/quickadd.Parse` 与 `Session`，接通时间识别、全局快捷键及原应用焦点恢复；不引入 WebView、Wails 或 SQLite。正式安装包和日常任务资料未替换。

## 使用与行为

在 `-native-main` 中按 Control + Shift + Space，或从任务页、设置、应用 File 菜单、独立菜单栏打开。540 × 260 透明外框窗口按需创建并复用，使用当前三主题。按鼠标所在显示器工作区居中偏上摆放；小工作区限制尺寸和边距，多屏运行尚未验证。

时间识别默认开启，支持标题开头的今天 / 明天 / 后天、数字或中文小时、点半、分钟与上午 / 下午等时段。预览显示时间和移除时间前缀后的标题；长标题预览限制一行。例：“明天下午3点 联系客户”保存为“联系客户”及明天 15:00。关闭识别则整句保存、截止时间为零。新任务默认未固定，可勾选固定；识别截止时间不自动开启提醒，普通优先级、非临时任务。

预览与保存重新调用同一解析函数，使用本次打开的固定日期基准；跨午夜及失败重试不改变已预览日期。再次打开失焦窗口时更新日期基准。无效时间、只有日期没有标题、多行文本及标题超限拒绝保存，保留输入并显示错误。资料原子写入失败时保留标题 / 选项 / 会话，重新聚焦后 Enter 重试。重复提交、保存中取消 / 重入、旧会话版本重放均被拒绝。原生持久提交仍在现有串行执行器同步完成，本轮未改成异步存储队列。

取消或保存成功后清空输入、恢复默认选项并隐藏窗口；仅在实验应用仍在前台时恢复之前的应用或自有窗口。点击外部应用自动收起并保留草稿 / 选项，不抢回焦点。主窗口编辑草稿独立保留。焦点对象在隐藏 / 关闭 / 退出时释放；终止的目标应用不再激活。开启快速添加会结束当前卡片 / 拖动 / 整理交互。实机发现隐藏窗口阻止退出，已修正：正常关闭等同取消，应用退出时允许真正关闭，并补上回归测试。

## 快捷键与诊断

MyGo v0.2.16 的 macOS 快捷键 API 使用非独占 Carbon 注册。实验沿用正式版独占语义，以 PureGo 注册独立 Carbon handler，校验事件 signature / ID 后才分发，退出释放注册和 handler；无需新增系统权限。Windows 使用 MyGo `GlobalShortcut`，焦点通过 Win32 保存和恢复，当前只交叉编译，无运行验证；其他平台明确提示未接入。

注册失败在设置页提示可能被占用，备用入口仍可用；解除冲突后重启。本机运行实验前，Control + Shift + Space 已被其他应用占用（独占探针 OSStatus=-9878），实验正常显示冲突提示。没有退出或更改该应用，正常按键的注册成功 / 真实回调到达未在本轮实机验证。

仅为诊断提供：

- `-native-main -output <目录> -quick-add-test-shortcut`：macOS 注册独立 Control + Option + Shift + F19，设置页标注诊断模式；不改变正常快捷键配置，不持久化。
- `-probe-only -output <目录> -quick-add-target-pid <自有测试PID>`：macOS 独立背景输入窗口，按钮向另一实验进程发送 SIGUSR2。目标仅在 `-native-main -output` 下监听，日志标记 `source=fixture-request`。不模拟系统按键，不能充当全局键盘验收。使用独立 bundle ID `io.sidelet.mygo-quick-probe` 的复制包区分窗口，所有资料和日志位于构建目录。

独占探针扩展了 `quick-add-fixture` 参数；该诊断按键实际验证空闲 → 运行时占用 → 正常退出后释放。未注入或合成系统事件。

Computer Use 创建三条合成任务：识别“明天下午3点 联系客户”并 Enter 保存、关闭识别固定整句标题、从独立背景输入窗口识别“后天上午九点半 外部保存验收”并保存。持久文件核对标题、日期、固定与不提醒状态，拒绝 / 取消 / 失焦草稿均未混入。实际无效时间提示、主窗口草稿保留与三主题预览截图通过。
